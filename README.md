# AI-Based Student Performance Prediction

## About the Project
This project uses Machine Learning to predict student academic
performance based on relevant academic and study-related factors.

## Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Git and GitHub

## Planned Features
- Student dataset analysis
- Data preprocessing
- Data visualization
- Machine Learning model training
- Model evaluation
- Student performance prediction
- Interactive web application
